# 시설팀 대시보드 다운로드

이 저장소는 시설팀 대시보드 Windows 설치 파일과 릴리스 안내만 공개합니다.

## 설치

1. [최신 릴리스 페이지](https://github.com/MalGungKJ/app_facility-dashboard-releases/releases/latest)를 엽니다.
2. `FacilityDashboard-버전.zip` 파일을 다운로드합니다.
3. ZIP을 푼 뒤 안에 있는 설치 파일을 실행합니다.

기존 설치가 있으면 삭제하지 않고 새 설치 파일을 실행해 업데이트합니다. 운영 데이터, 과거 보고서, 로그와 애플리케이션 소스 코드는 이 저장소에 포함되지 않습니다.
